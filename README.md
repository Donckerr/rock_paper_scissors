Небольшая простая игра "Камень, ножницы, бумага", разработанная на языке Python, в двух версиях: консольная и с графическим дизайном на PyGame

Особенности:
    Игра с компьютером один на один, где второй всегда выбирает случайную комбинацию
    Подсчет очков игрока и компьютера, с последующим определением победителя
    Сохранение счета в JSON
    Игра в двух вариациях: консольная (consoleGame.py) и графическая (pygame_main.py)

Установка:
    Воспользуйтесь командой git clone <URL_ЭТОГО_РЕПОЗИТОРИЯ>, следом, чтобый войти в репозиторий воспользуйтесь cd rock_paper_scissors
    Установите зависимости для игры в графическую версию командой pip install -r requirements.txt

Запуск:
    Воспользуйтесь командой python pygame_main.py для игры в графическую версию:
        выбирайте необходимую комбинацию для совершения хода, компьютер автоматически сделает свой выбор, после чего результат и счет будут отображены на экране
    Воспользуйтесь командой python consoleGame.py для игры в консольную версию:
        пропишите небходимую комбинацию в терминале для совершения хода, компьютер также автоматически сделает свой выбор
    Счет сохраняется в score.json для графической версии и score_console.json для консольной версии соответственно
